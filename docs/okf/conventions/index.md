# conventions

The rules the code and this bundle follow.

* [How this bundle is written](okf-bundle.md) - The rules for every file under docs/okf, and the one rule for talking about the other repositories.
* [Code style](code-style.md) - Short modules, comments that describe the current state, every value a parameter, and one place for each rule across Rust, Python, SQL and TypeScript.
* [Testing](testing.md) - What each suite proves, which suites need a built warehouse, and the rule that every data rule has a test.
